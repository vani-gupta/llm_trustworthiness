# Evaluating the Trustworthiness of LLM-Generated Answers on Swiss Political Information

## Project Overview

This project investigates the trustworthiness of answers generated by Large Language Models (LLMs) to questions about Swiss political and referendum-related information. The study uses official German-language *Botschaften* published by the Swiss Federal Council as source documents.

The objective is to develop and evaluate a systematic framework for assessing the quality and trustworthiness of LLM-generated answers. Key evaluation dimensions include factual accuracy, source-groundedness, completeness, neutrality, and traceability of supporting evidence.

The research workflow covers source-document collection and preparation, question-set generation in German and English, answer generation using different LLMs, and systematic evaluation using an independent LLM judge, supplemented by human validation where applicable.

## Research Context

This project is conducted as part of a Master's thesis in the **MSc Applied Information and Data Science programme at Lucerne University of Applied Sciences and Arts (HSLU)**.

It also contributes to the **SmartInfo project**. The research aims to support the assessment of trustworthy AI-generated information about Swiss political topics and contribute to the development of reliable AI-assisted information provision, with appropriate attention to licensing and data-use requirements.

- **PyMuPDF** — PDF text extraction.
- **Requests and cURL** — source-document retrieval and interaction with the Fedlex SPARQL endpoint.
- **Git and GitHub** — version control and project management.

Model assignments reflect the current experimental setup and may change during the research.

## Research Workflow

1. **Source collection:** Retrieve metadata and download selected official Federal Council *Botschaften*.
2. **Document preparation:** Extract page-level text and create structured manifests.
3. **Question generation:** Generate and review questions grounded in the source documents, retaining German originals and English translations.
4. **Answer generation:** Submit the same fixed question set to the selected LLMs.
5. **Trustworthiness evaluation:** Assess generated answers against source evidence using an independent LLM judge and defined evaluation criteria.
6. **Analysis and validation:** Compare model performance, examine error patterns, and validate findings where possible.

## Data Management and Reproducibility

Raw source PDFs and extracted source text are excluded from version control. Intermediate question-generation candidate files are also excluded, while curated question sets, manifests, notebooks, and research outputs may be version-controlled as appropriate.

The notebooks document the main stages of the workflow. Reproducing the experiments may require access to the research server, a configured Python environment, a running Ollama instance, the required models, and internet access for source collection.

Prompts, model versions, data-processing decisions, and evaluation settings should be recorded to support reproducibility and traceability.
